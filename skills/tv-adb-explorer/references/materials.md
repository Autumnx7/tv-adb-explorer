# 素材包与断点约定

```
app-run/
  index.html                 离线素材浏览索引（需与 steps 一起移动）
  REPORT.md                  范围、停止原因、未探索入口
  device.json                型号、系统、App 版本、分辨率
  pages.json                 AI 归类页面与首次观察编号
  transitions.json           前一步操作与下一步观察的关系
  blocked.json               分支阻塞和动作拦截
  state.json                 所有步骤、frontier、待执行动作、下一编号
  events.jsonl               故障与步骤日志
  steps/000001/
    screen.png               ADB 原始二进制截图
    ui.xml                   可用时保存；缺失不是空白页面
    window.txt               当前前台窗口证据
    capture.json             时间顺序中的捕获摘要、XML 错误、截图哈希
    decision.json            AI 判断，不能当作原始事实
    execution.json           pending / sent / not_executed
```

用截图编号串起入口、默认焦点、方向移动、滚动、弹窗、返回恢复。`sent` 只说明 ADB 命令送出，效果必须用下一步截图验证。`transitions.json` 标识续跑后的因果断点。UI 树可能为空、不完整，SurfaceView/Canvas/视频界面尤其如此；视觉继续可探索但不编造控件结构。安全窗口可能黑屏，保留问题，不绕过系统限制。

续跑不重放上次未确认的动作，而是重新观察。每次运行重新计时和计步，旧素材累计保留。设备、App 包名不一致或系统/App 版本/分辨率变化时要求新建目录，不混成同一版本证据。账号、网络、外设变化目前不能自动检测，操作者应另建目录或在报告补充条件。

页面去重为 AI 语义归类；全量截图保留，PNG SHA256 可供精确重复核对。不是数学上完备的状态空间遍历：推荐流、滚动内容、账号状态、外设和网络条件可形成无限状态，未提供页面清单时不能给出可信“覆盖率百分比”。

默认执行一张截图→一次决策→一个按键，速度有限但能追溯。尚不提供录屏、动画时序测量、OCR 坐标裁切、APK 资源提取、多设备并行。素材可与后续代码/Spec/设计稿合并生成 H5，此 Skill 到素材包为止。

文件包含设备序列号、截图和可见账号内容，应存放在允许的本地目录。使用 Codex 做视觉判断会将截图、XML 和探索摘要发给 Codex 服务；GitHub 仓库只发布工具，不自动同步素材。分享素材前人工检查敏感信息。
